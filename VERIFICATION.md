## What the certificates establish

The two assisted certificates concern the original uniform 243-pair game on `ψ_XX,N ⊗ Φ₉`. The prescribed physical-state strategy has loss `2 E(ψ_XX,N)/243`. The primary verifier transfers the square root of the duplication defect, with a linear omitted-model-mass bound, to obtain the physical loss. It separately reports the generic transfer for applying model POVMs to the physical state. The 262,144-site control is a lower bound for that prescribed strategy, not for the optimal game loss.

Floating-point eigensolvers propose roots and vectors. The primary assisted verifier then encloses quadrature roots and weights, kernel entries, eigenpair residuals, omitted singular mass, rank counts, and scores using directed or exact integer arithmetic. It checks every printed error cap and each fixed distance budget. Different eigensolver proposals can change raw residual fields; every successful run must meet the fixed budgets. The independent implementation uses a different perturbation estimate, rational mode ratios, and Schmidt prefix.

The chain-only certificate retains its separate rounding-error analysis. Its geometric model's score is 0.000410720762 or less; the rounded physical-state bound is 0.000461. The revision 3 audit checked the covariance, compression, rounding bounds, and transfer, and revision 4 expands the explicit inequality chain. A separate exact dyadic score computation also reproduced the strict separation.

The four-spin result concerns the tagged tilted-CHSH game and plays the original-game branch classically. Its SymPy checker evaluates the full physical spin Hamiltonian and Bell observables. SymPy is included in the dependency file.

The XXZ theorem is a spectral theorem for the explicitly defined corner-transfer-matrix probability law as Δ decreases to one. Its identification with the infinite-volume physical Néel state is an imported CTM input, not proved here. The fixed-coupling circuit Hamiltonians are exactly conjugate to XX. The XX/Ising and CTM asymptotic laws are analytic results proved from their stated spectral inputs; the displayed finite samples are pre-asymptotic.

## Reproduction environment and integrity

The reference checks used Linux x86-64, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8, and SymPy 1.14.0. The release runner disables Python optimization and uses one BLAS thread. SHA-256 checksums cover every distributed payload file except the repository metadata files `CITATION.cff` and `.zenodo.json`. `verification-output.txt` is the reference output recorded for revision 4. Version 1.0.0 changes no program or data file, so a run on this version should match it apart from the checksum count on the first line (116 here) and the test timing. `verify_manifest.py` checks those bytes before the calculations run. A regenerated plot or build can change file bytes; the supplied manifest identifies the distributed version.
